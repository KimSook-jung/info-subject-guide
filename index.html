FAQ

자주 묻는 질문

정보교과에 대한 흔한 오해들을 풀어드립니다.

수학 실력보다 논리적 사고력이 훨씬 중요합니다. "어떤 순서로 문제를 풀까?"를 생각하는 과목이에요. 복잡한 수식보다 도구(파이썬, 엑셀)가 계산을 대신해줍니다. 데이터 과학도 기초적인 평균·분포 개념 정도면 충분합니다.
완전히 처음 시작하는 학생을 기준으로 가르칩니다. 오히려 백지 상태가 잘못된 습관 없이 배우기 좋을 때도 있어요. 소프트웨어와 생활은 복잡한 코딩 없이 블록 코딩, 노코드 도구로도 프로젝트를 완성할 수 있습니다.
오히려 문과 계열 학생에게 더 차별화된 무기가 됩니다. 경영·경제·사회학 지망생이 데이터 과학을 이수하면 입시에서 뚜렷하게 눈에 띕니다. 인공지능 기초의 "AI 윤리·사회적 영향" 단원은 법학·철학 지망생에게도 강력한 생기부 소재가 됩니다.
정보(1학년 필수) → 인공지능 기초 → 데이터 과학 3과목 조합을 추천합니다. 실제 AI 모델 구현과 데이터 분석 경험이 생기부에 강력한 근거가 됩니다. 선택 자체가 진로 의지의 증거가 되는 과목들입니다.
우리 학교 편성표상 두 과목 모두 선택군G에 편성되어 있어, 일반적으로 둘 중 하나를 선택하게 됩니다. IT·데이터 계열 지망이라면 데이터 과학을, 내 관심 분야와 SW를 융합하는 프로젝트에 관심 있다면 소프트웨어와 생활을 추천합니다.
특히 추천합니다! 음악 생성 AI, 디지털 아트, 영상 편집 SW, 스포츠 데이터 분석 — 예체능과 SW의 융합은 지금 가장 뜨거운 분야입니다. 인문·예술 계열에서 정보교과를 이수한 학생은 오히려 희소해서 더 눈에 띄어요.
